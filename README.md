# Курсовая № 21 — визуализация списков и музыкальный плейлист

Сайт работает на **Python + Flask + HTML + CSS**. JavaScript не используется.

## Запуск

```bash
python -m pip install -r requirements.txt
python app.py
```

Откройте `http://127.0.0.1:5000/`, затем ссылку «Практический пример: музыкальный плейлист».

## Страница плейлиста

- Всегда используется `CircularDoublyLinkedList` из `linked_list.py`.
- «Добавить в начало» вызывает `Playlist.add_song()` → `insert(0, title)`.
- «Удалить текущую» вызывает `Playlist.remove_current()` → `remove_cursor()`.
- «Предыдущая» и «Следующая» вызывают `move_cursor(-1)` и `move_cursor(1)`.
- Есть кнопки очистки и восстановления примера из трёх песен.
- Плейлист отображается строками в порядке от `head`; текущая песня выделена.
- Кольцевого сдвига и выбора структуры на странице плейлиста нет.
- Состояние плейлиста хранится отдельно от главной страницы, в Flask session.

Изменены `playlist.py`, маршрут `/playlist` в `app.py`, `templates/playlist.html` и добавлены стили к `static/style.css`.


### Последние изменения
- Каждая композиция показывается отдельной строкой, текущая песня выделена.
- Добавление песни выполняется через `insert(0, title)` и сразу устанавливает курсор на новый первый узел.
- Для обновления оформления в ссылку на CSS добавлена версия (против кэширования).


## Исправление порядка песен

При переходах «Следующая» и «Предыдущая» меняется только позиция курсора;
список песен в сессии не перезаписывается. Порядок изменяется лишь при
добавлении песни в начало, удалении по курсору, очистке или загрузке примера.
Если ранее сайт был открыт в нескольких вкладках или запущены несколько
копий Flask, рекомендуется остановить старые серверы и обновить страницу.

Проверка: `python -m unittest discover -s tests -v` (после установки Flask).
